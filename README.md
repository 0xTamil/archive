## Archive

## C Programming

- **[Crafting Interpreters](https://craftinginterpreters.com/)**, by Robert Nystrom — You'll learn both high-level concepts around parsing and semantics and gritty details like bytecode representation and garbage collection.
- **[Beej's Guide to C Programming](https://beej.us/guide/bgc/)** — The second volume of Beej's Guide to C: the standard library reference, complete with examples. (Inspired by the incomparable Turbo C Bible.)
- **[The C Book](https://publications.gbdirect.co.uk//c_book/)** — The online version of *The C Book*, second edition, by Mike Banahan, Declan Brady and Mark Doran, originally published by Addison Wesley in 1991. Made freely available.
- **[The C Programming Language (K&R)](https://en.wikipedia.org/wiki/The_C_Programming_Language)**, Not free online, but still the canonical, dense introduction to C by its creators. Most low-level devs read this first.
- **[Learn C](https://learn-c.org/)**, Interactive, browser-based exercises for getting comfortable with C syntax and idioms quickly.
- **[C FAQ](https://c-faq.com/)**, A deep, battle-tested collection of answers to the subtle gotchas C programmers run into (pointers, arrays, undefined behavior).

## Systems Programming

- **[The Linux Programming Interface](https://man7.org/tlpi/)**, Michael Kerrisk's reference on Linux/UNIX system calls, processes, IPC, and threads; the modern successor to APUE.
- **[Beej's Guide to Network Programming](https://beej.us/guide/bgnet/)**, The standard friendly intro to sockets programming in C, by the same author as Beej's Guide to C.
- **[Build Your Own X](https://github.com/codecrafters-io/build-your-own-x)**, A huge index of tutorials for building your own shell, database, HTTP server, Docker, regex engine, and more, from scratch.

## CS Fundamentals

- **[Beej's Guide to Learning Computer Science](https://beej.us/guide/bglcs/)**, A short primer aimed at new computer science students. Not about how to program, but about how to approach programming problems in general — techniques for setting yourself up for success.
- **[Teach Yourself CS](https://teachyourselfcs.com/)**, A tightly curated self-study curriculum covering the core CS subjects that actually matter for working programmers.
- **[CS50: Introduction to Computer Science (Harvard)](https://cs50.harvard.edu/x/)**, Broad, well-taught foundation covering C, algorithms, memory, and more.
- **[The Missing Semester of Your CS Education (MIT)](https://missing.csail.mit.edu/)**, Practical tooling skills (shell, git, debugging, version control) that CS courses usually skip.

## Algorithms & Data Structures

- **[VisuAlgo](https://visualgo.net/)**, Visualizations of algorithms and data structures in motion; great for building intuition.
- **[MIT 6.006: Introduction to Algorithms (OCW)](https://ocw.mit.edu/courses/6-006-introduction-to-algorithms-spring-2020/)**, Full free course with lecture videos, notes, and problem sets.

## Operating Systems

- **[Operating Systems: Three Easy Pieces (OSTEP)](https://pages.cs.wisc.edu/~remzi/OSTEP/)**, Free, excellent textbook covering virtualization, concurrency, and persistence, with projects.
- **[xv6: a simple Unix-like teaching operating system (MIT)](https://pdos.csail.mit.edu/6.828/2023/xv6.html)**, A minimal, readable OS used in MIT's 6.828/6.S081 course; you read and extend real kernel code.
- **[MIT 6.S081: Operating System Engineering](https://pdos.csail.mit.edu/6.828/2023/schedule.html)**, Course materials, labs, and xv6 source for building real OS features (page tables, scheduling, file systems).

## Computer Architecture

- **[Computer Systems: A Programmer's Perspective (CS:APP)](https://csapp.cs.cmu.edu/)**, CMU's book on how programs are represented, executed, and interact with hardware; free labs available.
- **[nand2tetris](https://www.nand2tetris.org/)**, Build a computer from logic gates up to a working OS and compiler; extremely hands-on.

## Compilers & Interpreters

- **[Writing An Interpreter In Go](https://interpreterbook.com/)** and **[Writing A Compiler In Go](https://compilerbook.com/)**, Thorsten Ball's approachable, project-based books on building a language from scratch.
- **[LLVM Kaleidoscope Tutorial](https://llvm.org/docs/tutorial/)**,  Official walkthrough of building a small language front-end targeting LLVM IR.
